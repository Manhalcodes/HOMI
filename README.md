# Homi - Personal Journal App

A modern journaling application with AI assistance, built with React, Vite, and Tailwind CSS.

## Features

- 📝 Create and save journal entries
- 😊 Track your mood
- 🤖 Get AI-powered insights and suggestions
- 🎨 Clean and responsive design

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## Technologies Used

- React 18
- Vite
- Tailwind CSS
- React Icons
